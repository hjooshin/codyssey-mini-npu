\# Mini NPU Simulator



\## 1. 프로젝트 소개

Python으로 구현한 Mini NPU 시뮬레이터입니다. 입력 패턴과 필터를 비교하여 MAC 연산을 수행하고, 연산 결과와 실행 시간을 분석합니다.



\## 2. 주요 기능

\- 사용자 입력 모드: 3×3 필터와 패턴을 직접 입력하여 분석

\- JSON 분석 모드: data.json에 저장된 여러 패턴 분석

\- Cross와 X 필터의 MAC 점수 계산

\- 점수 비교를 통한 Cross, X, UNDECIDED 판정

\- 기대 정답과 비교하여 PASS/FAIL 출력

\- 3×3, 5×5, 13×13, 25×25 크기별 MAC 성능 비교

\- 잘못된 입력 및 JSON 데이터 오류 처리



\## 3. 실행 방법

Python이 설치된 환경에서 프로젝트 폴더로 이동한 뒤 실행합니다.



```cmd

python main.py

```



실행 후 1번 또는 2번 모드를 선택합니다.



\## 4. MAC 연산이란?

MAC(Multiply-Accumulate)은 두 숫자를 곱하고 그 결과를 계속 더하는 연산입니다.



이 프로그램에서는 입력 패턴과 필터에서 같은 위치에 있는 숫자끼리 곱한 뒤 모두 더하여 점수를 계산합니다.



\## 5. 판정 방법

\- Cross 점수가 높으면 Cross

\- X 점수가 높으면 X

\- 두 점수 차이가 매우 작으면 UNDECIDED



부동소수점 오차를 고려하여 epsilon(1e-9)을 사용했습니다.



\## 6. JSON 분석 결과

\- 전체 테스트: 6개

\- PASS: 3개

\- FAIL: 3개

\- FAIL 패턴: size\_5\_1, size\_13\_2, size\_25\_1



FAIL은 프로그램 실행 오류가 아니라 계산 결과와 기대 정답이 일치하지 않았음을 의미합니다.



\## 7. 성능 분석

MAC 계산에 필요한 곱셈 횟수는 N×N 행렬에서 N²회입니다.



따라서 행렬 크기가 커질수록 연산량이 증가하며, 시간 복잡도는 O(N²)입니다.



실행 시간은 perf\_counter()로 측정하고 10회 반복한 평균을 사용했습니다.



\## 8. 예외 처리

\- 잘못된 메뉴 선택

\- 숫자가 아닌 입력

\- 행렬 크기가 잘못된 입력

\- data.json 파일 누락

\- JSON 문법 오류

\- 필수 항목 누락

\- 행렬 크기 및 데이터 형식 오류
